# ZEA AI 2.0

Modern AI chat frontend + Express backend + OpenRouter web search.

## Struktur
- server.js
- src/services/openrouter.js
- public/index.html
- public/css/app.css
- public/js/app.js
- .env.example

## Instalasi
1. npm install
2. cp .env.example .env
3. Isi OPENROUTER_API_KEY di .env
4. Sesuaikan OPENROUTER_MODEL jika diperlukan
5. npm start
6. Buka http://127.0.0.1:3000

API key hanya disimpan di backend (.env), bukan di frontend.
